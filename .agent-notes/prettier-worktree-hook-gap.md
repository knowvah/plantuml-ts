## Observation: husky hooks do not run in a fresh git worktree
- **Context**: CI run 35935330151 (main 0df81700) failed `npm run format:check` on 50 files, all last touched by class-divergence-drive commits made in worktrees.
- **Finding**: core.hooksPath is `.husky/_` (relative, resolved per worktree). `.husky/_/` is generated by `husky` (npm `prepare`) and self-gitignored, so a new worktree has no hook shims and git skips pre-commit silently. Reproduced: commit of an unformatted file in a fresh worktree landed unformatted, no output. 0620712b1's own blob was unformatted (not a merge artifact).
- **Impact**: any worktree used for commits needs `npx husky` (or `npm install`) run in it first; otherwise lint-staged never formats. CI `format:check` (e6b6294f0) is the only backstop.
- **Confidence**: High
