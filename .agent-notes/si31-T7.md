# SI31 T7 — Close-out

## Observation: T0's original baseline files are unrecoverable from git — they are gitignored

- **Context**: T7 close-out needed to diff the harness/manifest against T0's
  ORIGINAL pin (before six re-pins), per the task's erratum 4.
- **Finding**: `test-results/state-declared-size-baseline.jsonl` and
  `test-results/render-manifest-baseline.json` are gitignored
  (`test-results/` is not `git add`-able) and are overwritten in place by
  every batch's gate. `git show <T0-commit>:test-results/...` fails with
  "exists on disk, but not in <commit>" — the file was never tracked, so no
  git history exists for any prior state of it.
- **Impact**: A byte-for-byte `harness-diff.py`/`manifest-diff.py` run
  against T0's literal original file is not reproducible after the mission
  closes. The only durable record of T0's original state is (a) the summary
  line + per-row values written into `.agent-notes/si31-T0.md`, and (b) the
  decision journal's per-batch stated deltas. T7 cross-checked both against
  a fresh full harness run today and they agree exactly
  (`273/2660/2576/47/37/0/39`, chaining `60→54→53→48→47→47` with no gaps).
  A future mission wanting the same guarantee should either commit a copy
  of T0's baseline under a tracked path, or accept that the summary-line +
  journal chain is the durable artifact once `test-results/` re-pins.
- **Confidence**: High — reproduced the `git show` failure directly, and
  independently verified the reconstructed numbers via a live harness run.

## Observation: mission task file's row-count arithmetic did not add up; corrected in close-out

- **Context**: T7's own task file (`batch-7/T7-close-out.md`, written before
  G20b/G15 joined) and the orchestrator's task-launch message both asserted
  "14 of 16 target rows closed" while also naming 3 rows as open with
  mechanisms.
- **Finding**: 14 + 3 = 17, not 16. Direct per-row measurement (matching
  each of the 16 target rows against its `.agent-notes/si31-T0.md` recorded
  value) and the harness's own `+13 exact / −13 mismatched` delta both
  independently land on **13** closed, not 14. The close-out states the
  reconciled number (13 of 16) with the row table as evidence, and flags
  the discrepancy explicitly rather than repeating the "14" claim
  uncorrected.
- **Impact**: Any downstream reference to this mission's exit count should
  say 13, not 14. `planning/mission-index.md`'s SI31 row and
  `plans/state-residual-fix-batch/README.md`'s close-out both use 13.
- **Confidence**: High — corroborated two independent ways (row-level
  measurement and harness arithmetic).
