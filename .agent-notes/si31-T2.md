## Observation: baseline harness JSONL is `--mismatched-only` output
- **Context**: Running `harness-diff.py` against the pinned
  `test-results/state-declared-size-baseline.jsonl` for SI31 T2.
- **Finding**: `scripts/measure-composite-declared-size.ts`'s default (no
  flag) output prints every row (2660 for the full state corpus); the
  pinned baseline file has only 97 lines (96 rows + 1 summary) but its
  `summary` line still reports the full-corpus totals
  (`declarations:2660`). The baseline was generated with
  `--mismatched-only` (rows where `match===false`, i.e. mismatched +
  lastDigit rows), not the unflagged full dump. Running `harness-diff.py`
  against an unflagged "now" run floods the diff with thousands of
  spurious `APPEARED` rows (every previously-exact row looks new, since
  the baseline never printed it).
- **Impact**: Any future task re-pinning or diffing against
  `state-declared-size-baseline.jsonl` must regenerate "now" with
  `npx jiti scripts/measure-composite-declared-size.ts --mismatched-only`,
  not the bare command. Worth a one-line note in
  `plans/state-declared-size-fix/scripts/harness-diff.py`'s own docstring
  for the next mission that reuses it.
- **Confidence**: High — directly reproduced (unflagged run: thousands of
  APPEARED rows; `--mismatched-only` run: `OK: 6 rows went exact, 0 rows
  appeared or grew`, matching the T2 fix exactly).
