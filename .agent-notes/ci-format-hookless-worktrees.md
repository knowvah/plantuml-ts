## Observation: agent worktrees run no git hooks
- **Context**: main CI red since 2026-10-02 (run 37837304051, step `format`).
- **Finding**: `core.hooksPath` is the relative `.husky/_`, generated by husky and gitignored, so it exists only in the main checkout. In a `git worktree` it resolves to a missing dir and git silently runs no pre-commit hook; lint-staged (prettier + eslint --fix) never ran on agent commits. Merge commits do not re-run lint-staged on merged content. 44 files reached main unformatted. Because `format` precedes the test step in CI, tests have not run on main in CI since 2026-10-02.
- **Impact**: every mission's `mkwt.sh` must link `.husky/_` (lgm's does as of 1fa1d621b); run `npx prettier --check .` before any merge to main.
- **Follow-up**: formatting pushed `src/core/svek/image/EntityImageDescriptionTextBlock.ts` to 504 lines; `src/diagrams/activity/dispatch-support.ts` was already 523. Both exceed the 500-line hook limit — split in a cleanup PR.
- **Confidence**: High (reproduced `prettier --check .` = 44 files on b46435b10; `ls .husky/` in a worktree shows no `_`).
