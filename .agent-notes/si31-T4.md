## Step 1 (pre-condition) — ANSWERED: the record's premise HOLDS. Proceed.

- **Context**: T4 opens with a pre-condition, not code. SI29's record
  attributes `gokife-89-boja382`'s opaque south cap to its own
  `skinparam state { backgroundColor<<statemachine>> LightYellow }`. The
  worry was that a stereotype-scoped skinparam might resolve through
  `SName.name`, leaving `SName.body` transparent and making
  `RoundedSouth.drawU` early-return — which would make the stated gate wrong
  (mission STOP 9).
- **Finding**: it resolves through **`SName.state` alone**, which `matchAll`
  admits into the `…state.body` query. Chain, all under
  `~/git/plantuml/src/main/java/net/sourceforge/plantuml/`:
  1. `style/FromSkinparamToStyle.java:293-301` — ctor splits
     `stateBackgroundColor<<statemachine>>` → `key="stateBackgroundColor"`,
     `stereo="statemachine"`.
  2. `style/FromSkinparamToStyle.java:204` —
     `addConvert("stateBackgroundColor", PName.BackGroundColor, SName.state)`.
     The declaration's style names are `{state}` — **NOT** `{state, name}`.
     This single line settles the pre-condition.
  3. `style/FromSkinparamToStyle.java:395-407` (`addStyle`) — signature
     `StyleSignatureBasic.of(SName.state).addStereotype("statemachine")`,
     and the value's priority is raised by
     `StyleLoader.DELTA_PRIORITY_FOR_STEREOTYPE` = 1000
     (`style/StyleLoader.java:178`).
  4. `svek/Cluster.java:469-470` — the south query is
     `EntityImageStateCommon.STYLE.addSName(SName.body)
      .withTOBECHANGED(group.getStereotype()).getMergedStyle(sb)
      .value(PName.BackGroundColor)`, i.e. element signature
     `{root, element, stateDiagram, state, body}` + the stereotype
     (`svek/image/EntityImageStateCommon.java:61-62` defines `STYLE`).
  5. `style/StyleSignatureBasic.java:212-216` (`matchAllImpl`) — a
     declaration matches when
     `element.key.snames.containsAll(declaration.key.snames)` and
     `element.stereotypes.containsAll(declaration.stereotypes)`.
     `{state} ⊆ {root, element, stateDiagram, state, body}` ✓ and
     `{statemachine} ⊆ {statemachine}` ✓ — so the `SName.state`-scoped
     skinparam declaration DOES reach the `body` query.
  6. `style/StyleStorage.java:102-116` → `style/Style.java:121-135` →
     `style/ValueImpl.java:62-73` → `style/DarkString.java:50-58` — merge
     keeps the higher-priority value. The skinparam-derived LightYellow
     (load counter + 1000) beats `plantuml.skin:269-271`'s
     `body { BackGroundColor transparent }` (plain load counter).
  7. Therefore `southBackcolor` is non-transparent and
     `svek/RoundedSouth.java:66-67`'s `if (backColor.isTransparent()) return;`
     does not fire — the cap is drawn.
- **Corollary (same mechanism, no stereotype)**: gokife's un-stereotyped

- **Impact**: the gate is "resolve `BackGroundColor` at the
