## Observation: two numbers restated by earlier tasks did not need correction,
one measurement approach did
- **Context**: re-measuring every number before publishing it, per the
  orchestrator's explicit instruction and the mission's own two prior misses
  (T0's undiagnosed canvas flag, T2's `mefici-97-tudu030` 820×673).
- **Finding**: the harness byte-diff, the ratchet counts, and the coverage/
  wall-clock figures all reproduced exactly on independent re-run. The one
  genuine miss was mine: my first `git worktree` render at `f1720a14`
  reported ~1976 spurious "unexpected" movers because the worktree lacked
  `assets/stdlib` (gitignored, not checked out by `git worktree add`) —
  every fixture rendered as `{error: "...does not exist..."}` instead of a
  real hash, so nearly everything looked "moved" relative to the current
  tree. Running `npx tsx scripts/vendor-stdlib.ts` in the worktree first
  fixed it; the re-run matched the mission's own count exactly (41 movers,
  0 unexpected beyond one pre-existing untracked stray fixture).
- **Impact**: a `git worktree add` for comparison renders needs
  `vendor-stdlib.ts` run inside the worktree before `render-manifest.ts` —
  the stdlib assets are gitignored and not part of the checkout. Worth
  knowing before the next mission reaches for the same technique.
- **Confidence**: High — reproduced twice (broken, then fixed, in the same
  worktree).
