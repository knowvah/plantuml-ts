## Observation: unformatted files reached main past the lint-staged hook
- **Context**: CI on main red 2026-09-25..28 (3 merges); step failing was `npm run format:check`, before tests.
- **Finding**: 15 files from cdd2/cdd5 commits were not prettier-formatted although `.husky/pre-commit` runs lint-staged. How the hook was bypassed (worktree hooksPath, --no-verify, merge commits) was NOT determined.
- **Impact**: a red format gate hides the test step on CI; run `npx prettier --check .` before merging mission branches.
- **Confidence**: High (symptom), Low (bypass mechanism)

## Observation: worktree commits skip the pre-commit hook (bypass mechanism found)
- **Context**: cdd6 batch 3, T3d noticed prettier never ran on its worktree commits.
- **Finding**: `core.hooksPath` is the relative path `.husky/_`, which is gitignored and generated by `husky` only in the main checkout. In a `git worktree` the relative path resolves inside the worktree, where `.husky/_` does not exist, so git finds no hook and commits silently. Mission worktrees (mkwt.sh) are how unformatted files reached main.
- **Impact**: link `.husky/_` into every worktree (cdd6 mkwt.sh now does), and run `npx prettier --check` on a mission branch before merging it.
- **Confidence**: High (verified: `.husky/_` absent in `.claude/worktrees/cdd6-T3d`; `git config core.hooksPath` = `.husky/_`)
