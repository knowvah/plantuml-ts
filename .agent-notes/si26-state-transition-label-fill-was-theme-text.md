## Observation: a "zero movement" premise about a renderer default can be wrong even when the ratchet holds — pins may all be label-free
- **Context**: SI26 T5 moved state transition-label `fill` from `theme.colors.text` (`#181818`) to the arrow FontColor resolver default `#000000`; the brief predicted zero state movement and its ratchet (59 zero-diff pins) held.
- **Finding**: the full state SVG dump showed 80 fixtures moving `#181818 → #000`, every one toward jar (jar draws `#000` for all 325 state link-label texts). The 59 pinned state fixtures were exactly the ones WITHOUT a transition label, so the ratchet could not see the old defect. `theme.colors.text` (`#181818`) is the port's canvas-text colour and is not the jar's default for ANY text drawn from a `FontConfiguration` (`plantuml.skin:9` root `FontColor black`); `renderer-classifier-rows.ts:45-50` hard-codes `#000000` for the same reason.
- **Impact**: "the ratchet holds" is not evidence of zero movement — only the full per-engine dump (`.agent-notes/si25-class-svg-byte-identity-dump.md`) is. Any remaining `theme.colors.text` draw in a diagram renderer is a candidate defect; grep before assuming it is faithful.
- **Confidence**: High.
