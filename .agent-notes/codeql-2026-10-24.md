## Observation: `skinparam lengthAdjust` cannot reach the root group raw
- **Context**: Alerts 32/33 (`js/html-constructed-from-input`,
  `document-shell.ts:304-305`), new because sdd3-T2c rewrote line 305.
- **Finding**: `skinparam-key-handlers-table-c.ts` resolves the value through
  `LENGTH_ADJUST_BY_LOWER_NAME.get()` — the three names
  `SkinParam.java:1260-1267` accepts — so any other text becomes `undefined`
  and the default; `svg.ts#rootGroupOpen` writes only those literals. The
  defs operand is `collectDocumentDefs()` over the port's own escaped body.
  Probe: root `<g>` carried `lengthAdjust="spacing"`, zero `<script`, zero
  `on*=` attributes on class and sequence.
- **Impact**: Dismissed as false positives (same function as 26/27).
- **Confidence**: High.

## Observation: `PSystemVersion` tag stripping is display, not sanitisation
- **Context**: Alert 31 (`js/incomplete-multi-character-sanitization`,
  `PSystemVersion.ts:114`), file unchanged on the branch.
- **Finding**: `TAG = /<\/?\w+>/g` mirrors `PSystemVersion.java:249`; it
  strips the jar's own `<b>`/`<u>` creole tags from constant program strings
  (version, compile time, licence, `AUTHORS`). The only caller passes
  `withTag = true`; the lines are drawn as SVG `<text>` through the escaping
  text driver. Probe of `version`/`authors`: zero `<script`.
- **Impact**: Dismissed as a false positive.
- **Confidence**: High.
